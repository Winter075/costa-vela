**Costa Vela — Sunset Crimes** is an original 3D open-world crime game that runs entirely offline from static files. Drive or walk through Mirador Beach Boulevard, Halcyon Downtown, Tern Harbour and the Velvet Nightlife Strip. Steal cars, outrun a wanted level that escalates from Bluebird cruisers to RAM plows, roadblocks, a spotlight helicopter and SWAT, and work through eight linked jobs with a street race on the side. Cash, respect ranks, weapon upgrades and saves live in your browser.

## Run it

```sh
node serve.ts
```

Then open `http://localhost:8080` in a desktop browser. The game itself is `game/index.html`; it needs no build step and makes no network request at runtime.

## Controls

WASD drives or walks, Space is the handbrake, E enters and exits vehicles, mouse drag or arrow keys orbit the chase camera, 1–6 switch weapons and a click fires. Tab opens the weapon wheel, G opens the Tern Garage, R changes radio station and M mutes the audio.
